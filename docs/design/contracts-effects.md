## 2. Semantics

### 2.1 Contracts

**C1 (clauses).** A function item, inherent method, trait method declaration or impl method `f` has ordered lists `req(f)` and `ens(f)` of `(cond, message?, debug, pos)`. A type `S` has `inv(S)` (C9), spelled `invariant COND` after the type (K-I1).

**C2 (evaluation points and states).**
- C2.1 `requires` of a call `r = f(a₁..aₙ)` is evaluated in the caller after the operands and before any `BK_MUT2` activation or `WM` of the call (the `$pre` call precedes it, T3), with `f`'s parameters bound to the argument values (bit copies; `BORROWED` temporaries for needs-drop values; shared reborrows for `&mut`), in clause order; the first false clause fails with the call's position.
- C2.2 `ensures` is evaluated in the wrapper after `f$body` returns and before the wrapper's drops (the parameters' `WD` at `TK_RETURN`); `result` is the wrapper's `let result`; a `()` function has none (`contract.result`).
- C2.3 `old(e)` is evaluated at the wrapper's entry, after the caller's `requires` passed and before `f$body` (D17.2).
- C2.4 A `debug` clause is evaluated only under `--debug-contracts` (`volec test`; from R5 also the `--check-unsafe` gate row), at every `-O`; it never yields a fact (L2.5).
- C2.5 A false non-debug clause ends the program through `IK_CONTRACT` → `rt.panic`, exit 101, no unwinding; the line is `FILE:LINE:COL: requires|ensures|invariant failed: 'COND' of 'f' (DEF): v = ..`.

**C3 (typing of a clause: shared context).** With `shared(&mut T) = &T`, `shared(&'a mut T) = &'a T`, `shared(&mut [T]) = &[T]`, `shared(τ) = τ` otherwise: `f$pre`'s parameters are `shared(params(f))`, and the wrapper's `ensures` reads every `&mut` parameter through a shared view. Implementation shape **[V for the node layout]**: a reference type is a `NodeKind::TyPtr` (or `TySlice`) with `NODE_REF` and, for `&mut`, `NODE_REF_MUT` (`front/parser/types.vl:347-350`); `signature_copy(f, name, first, extra, shared: bool)` clears `NODE_REF_MUT` on each cloned Param's type node when `shared` and the node is not a raw pointer; `make_pre` passes `true`, `make_body` keeps the wrapper's signature (it must pass `&mut` to `f$body`) and, after `let result = f$body(..)`, pushes `let ?sN = &*pN;` for each `&mut` parameter `pN` and substitutes `pN ↦ ?sN` in the cloned conditions by a `replace_olds`-style walk (`replace_shared`; `old(e)` lets precede `f$body` and are not substituted). MVS edition: `shared` is the identity (C3.4).
- C3.1 A clause cannot write through a parameter by type; a write through `&T` of a non-`Freeze` `T` is caught by C4 (`interior`).
- C3.2 A by-value non-`Copy` parameter is read in place; a `move` of it in a clause is `error contract.move`.
- C3.3 `result` of `-> R` is a read-only place (a `move` is `contract.move`); for `R = &'a mut T`, `*result` may be read; reading `*self` (or any place borrowed by `result`) in that clause is `borrowck.use_borrowed` by D2.5 (the wrapper's `result` holds the `M` loan of `*self` through `'self : 'new : 'ret` until the return), with the contract-specific `help: 'self' is borrowed by 'result'; state the promise on '*result' or on 'old(..)'`. This is plan §5's rule, obtained from the borrowck rules.
- C3.4 MVS: no change.

**C4 (purity).** A clause is accepted iff `eff(cond) ⊆ {panic, diverge} ∪ U`, `U = {unsafe}` when the owner is an `unsafe fn` and `∅` otherwise, and `eff(cond)` contains no `alloc(_)`, `io`, `static`, `interior`, `sync`, `tls`, `thread`; ⊤ is impure. `contract.effect` names the effect and the call, with `--why`. Verified today: a clause of an `unsafe fn` is an unsafe context (its companion carries `FN_UNSAFE`), so `requires *p > 0` on `unsafe fn f(p: *const i64)` type-checks **[V]**; this design keeps that and adds nothing (K-I2). Why `unsafe` only there: a `debug requires` is the checked half of a SAFETY comment and must read what the comment talks about; a safe function has no SAFETY obligation to encode.
- C4.1 A passing check changes no observable state (so a discharged check is removable, L4); `debug` on/off changes nothing; Level 2 can read pure conditions as terms.
- C4.2 A `panic`/`diverge` inside a clause is reported as the panic's own line.

**C5 (`old(e)`).** Accepted iff `type(e): Copy`, `slots(type(e)) = []` (bc271 D3.3) and `type(e)` contains no raw pointer; else `error contract.old`. So `old(r)` for `r: &mut T` and `old(&x)` are rejected, `old(*r)` for `*r: Copy` and `old(v.len())` accepted; D17.2's loan cases become unreachable. `?oldN` is an ordinary `LF_TEMP` local read by `OK_COPY`.
- C5.1 A `debug` clause may not allocate either (K-U3): `old(e.clone_in(a))` is refused by C4 (a `debug` clause that allocates would change `--check-alloc`'s reports between test and release builds).

**C6 (generics).** Clauses are checked per instance (`fn_instance` in `desugar_call`, T3); L1 verdicts are per instance; a refutation names the instance (`in f<i64>`, as borrowck §14.2); messages are deduped by the instance key (D4.4(b)).

**C7 (trait methods).** For a trait method declaration `Tr::m` with `req(Tr::m)`, `ens(Tr::m)`, and an impl `I::m` with `req(I::m)`, `ens(I::m)`:
- C7.1 `I::m` may add `requires`: `req_eff(I::m) = req(Tr::m) ++ req(I::m)`, checked per instance at every statically dispatched site (direct, or through a bound in a monomorphized body: `desugar_call` resolves the instance and calls `I::m$pre`, which contains both lists, the trait's first), blaming the caller. No error and no warning (std2's `impl Index<usize> for [T]` with `requires i < self.len()` is the canonical case Rust's trait cannot carry). `query contracts Tr::m` lists what each impl adds.
- C7.1a (facts.) Per instance, the passing edge of each conjunct's switch at the site is a checked fact (L3.1). At `I::m`'s entry both lists are entry facts (L3.2). No template-level fact exists: the region-free/opaque instance (D4.4) carries `req(Tr::m)` only, and Level 2 verifying a generic body once uses `req(Tr::m)`/`ens(Tr::m)` (V4): that is where Liskov matters, as provability, not soundness.
- C7.2 `ens_eff(I::m) = ens(Tr::m) ++ ens(I::m)`, both checked in `I::m`'s wrapper, the trait's first.
- C7.3 A direct call of `I::m` checks `req_eff(I::m)` likewise.
- C7.4 A trait method with a default body is an impl for C7.1–C7.3.
- C7.5 Closures take no clauses (`error contract.closure`); an `Fn` bound carries none.
- C7.6 (0.27.2.1, as built.) The clauses of a trait method declaration are copied, at the expansion (T2), into every impl's method of that trait in the program, before the impl's own (a default body: below), each parameter renamed to the impl's by position; the trait is the one the impl names (its path's last segment, the trait declared in the program); the copies keep their positions, so a failure names the trait's line. `query contracts Tr::m` prints `req(Tr::m)` and `ens(Tr::m)`, then each impl's own lists and `req_eff`/`ens_eff` (C7.1, C7.2); `query contracts f` a function's lists. (0.27.3) A default body with clauses (C7.4) is written, at the expansion, into each rust-edition impl of its trait that does not define it and is in the trait's file, as the impl's own method with the default's clauses: a call of it checks them as an impl's (C7.1-C7.3). Not yet: a generic trait's default, a default with type parameters of its own in a generic impl, an impl in another file (each keeps the unchecked default). Cases `rust_t_contract_trait_default`, `rust_t_contract_trait_default_requires`.

**C8 (failure vs. violation).** `contract.violated` is a compile-time verdict of Level 1 (C11, L4.2); the run-time word is `requires failed` etc. (C2.5).

**C9 (type invariants and invariant newtypes).** For `S` in module `M` with `inv(S) ≠ []`:
- C9.1 `S` must have a non-`pub` field or variant payload, else `error contract.invariant_public`. Each clause is typed as `fn S$inv(self: &S) -> bool` under C3/C4.
- C9.2 A *boundary crossing* of `S` is: (a) `TK_RETURN` of a `pub` (or `pub(crate)`) function `g` of `M`, for each parameter of type `&mut S` and for `_0` when `type(_0) ∈ inv_types = {S, &S, &mut S, Option<S>, Option<&S>, Option<&mut S>, Result<S, _>, Box<S, _>}` (one level); (b) an `SK_CALL` from a body in `M` to a callee not in `M` (a generic callee, a closure parameter, a fn value, C), for each argument whose type is in `inv_types`: checked before the call (the callback problem); (c) an `unsafe fn` of `M` is a boundary like any other; raw pointers to `S` escape the model (C9.6).
- C9.3 At each crossing the builder emits, per place `P` of type `S`, the conjunct switches of `inv(S)[self := &P]` with `IK_CONTRACT` kind `invariant`, blaming `g`'s return or the call (`invariant failed: 'COND' of 'S' when 'S::push' returns`); `Option`/`Result`/`Box` through the discriminant or `*b.deref()`.
- C9.4 (soundness.) *Lemma:* if (i) every write to a private field of `S` and every literal of `S` is in a body of `M` (privacy) and (ii) no unsafe raw write reaches a private field of `S` outside `M`'s own SAFETY reasoning, then at every point of a body outside `M` every initialized place of type `S` satisfies `inv(S)`. *Sketch:* an outside body obtains or observes an `S` only through (a) a value returned from `M` (checked at return), (b) a `&S`/`&mut S` it held across a call into `M` — while `M` holds `&mut`, I3 says the outside body cannot read it, and the `&mut` parameter is checked at `M`'s return, (c) a callback from `M` (checked before the call), (d) its own copies of a valid `Copy S` (C9.5). Inside `M` intermediate states are free.
- C9.5 If `S` has a non-`Freeze` field, `inv(S)` may not mention it (`error contract.invariant_cell`).
- C9.6 (holes, counted.) `S` inside a container `M` mutates through `&mut Vec<S, A>`/`&mut [S]` is not checked at that function's return: `warning contract.invariant_deep` on such a `pub` fn of `M`, silenceable per item with `#[invariant(unchecked)]`, counted by `--print-checks`. Unsafe raw writes are the SAFETY comment's.
- C9.7 (newtypes.) `struct Port(u16) invariant self.0 < 1024;` with `pub fn new(v: u16) -> Option<Port>` in `M`: outside `M` the invariant is a *fact* (L1.2's invariant row), the one place a claim is used without a check at that point, justified by C9.4.
- C9.8 (`distinct`, K-I3.) `type X = distinct T invariant ..` becomes the one-field newtype `struct X(T) invariant ..` in the rust edition; `as` conversions become `X::new`/`.0`; the rust-edition parser rejects `distinct` with `try:` the newtype; the `#[niche_null]` attribute of `NonNull` moves to the newtype.
- C9.9 `debug invariant`: as `debug` clauses. C9.10 enum invariants are C9 over variants; loop invariants are not in this design.

**C10 (`debug requires` on `unsafe fn`).** The checked half of a SAFETY comment: C4 admits raw reads; C2.4's evaluation; no fact; `warning unsafe.unclaused` (counted by `query unsafe --summary`) on a `pub unsafe fn` with a SAFETY comment and no `debug requires`, so "unsafe fn without a clause → 0" is a printable number. A non-`debug` `requires` on an `unsafe fn` is allowed and always checked.

**C11 (`contract.violated`).** Emitted for a check site `k` in body `b` when `L1(b)` yields `Refuted(k, w)`: the conjunct is decided false at `k`'s point from facts of kind *checked* or *proven* (L1.2), with `w` the operands' intervals: `error[contract.violated] 'get(v, i)' violates 'requires i < v.len()' of 'get' (stack.vl:4:14): i in [3, 3], v.len() in [0, 3]`, `help:` naming the deciding fact. For a bounds, overflow, `/ 0` or `as E` site the code is `check.unconditional`. Reachability: a site is reachable unless a dominating `switch` on a *constant* excludes it (K-I4).
- C11.1 (`--allow`.) Both are errors, each `--allow=`-able. Under `--allow` the verdict is `Runtime(k)`, never `Discharged`: the check is emitted and runs; no fact is taken from its passing edge (it is unreachable, and the optimizer may fold the branch to the failing side as `fold_by_ranges` does for any decided branch); `--print-checks` lists it as `refuted (allowed)`.

### 2.2 Effects

**E1 (the lattice).** `Eff = P(B) × P(Allocs)`; user-visible `B_user = {io, panic, diverge, unsafe}` plus `alloc(A)` per allocator type and `alloc(extern)`; internal `B_int = {static, interior, sync, tls, thread, raw_panic, raw_diverge, unknown}`. Order: componentwise `⊆`; `⊤ = unknown`. `global` is renamed `static` in messages ("touches a `static mut` or a C static"), kept internally (threads' `sync.global`, `--verify-effects`, O2.2's memory mask), printable by `--why static`, with `global` an alias for one release. `#[pure]` = none of `io`, `alloc`, `static`, `interior`, `sync`, `tls`, `thread`; `#[no_alloc]`, `#[no_io]`, `#[no_panic]`, `#[effects(..)]` as today. Display `alloc(Gpa, Arena) io panic diverge unsafe`; `none`.
- E1.1 Why `static` stays internal rather than deleted: Rust's rule makes `&mut STATIC` an error (D6.2.5), so static access is `&raw` in `unsafe`; the bit still serves `--verify-effects`, threads and `#[pure]`; its 83% share (T17) was the compiler's statics (1(f)) and printing (already `io interior`).
- E1.2 (0.27.2.1, the renaming as built.) A set's display (`query effects`, `query show`'s `effects:`, `--print-effects`, the LSP's hover) leaves `static` out; `query effects F --why static` and `--has static` show it, and so does every message that names the bit (`effect.declared`, `contract.effect`, `#[pure]`): `static (touches a static mut or a C static)`. A declaration spells it `static`; `global` is accepted as its alias through 0.27.x (MVS std's `#[effects(global)]` unchanged; `--why global` and `--has global` too). The bit is one for both editions.
- E1.6 (0.28.0, a panic's effect.) A call of std2's `panic` or `assert_failed` (an instance of either) is `panic diverge` to its caller, and the graph has no edge to it: the message is written into the panic's own buffer and out through two C functions declared `#[effects(panic)]` and `#[effects(panic, diverge)]`, as MVS's `panic_str`, so neither the writers its Formatter's fn values reach by type (stdout's) nor the formatting it shares with the program are its caller's. std2's `assert` with a condition true as written is no effect (MVS's assertion), and its `debug_assert` is dropped outside test builds. A message with holes, written in place at the call, is the panic's as well: the holes' expressions are the caller's, the writes are not; and a search (`query effects --why`) and a clause's effects read the call the same way.

**E2 (meaning).** `S(f)` is `f`'s signature set; `c ∈ S(f)` means some execution of `f` may perform an action of class `c`: `io` a C function classified io or declared so; `alloc(A)` a call of a method of `impl Allocator for A` (the encapsulation rule; `alloc(&A) = alloc(A)` after 0.27.2's `impl Allocator for &A`); `alloc(extern)` C allocation; `static` a read, write or address of a `static mut`/C static; `interior` a write through a shared reference (root `UnsafeCell::get`); `panic` a run-time check that may fail, `panic()`, `unreachable()`, a C function that may not return; `diverge` an uncounted loop or recursion; `unsafe` the body contains an unsafe operation or is an `unsafe fn` (never transitive); `sync/tls/thread` as 0.21.

**E3 (declarations are signatures).**
- E3.1 `D(f)` the declared set (the chain's intersection) or ⊤ if undeclared; `I(f)` the inferred set (E5); `S(f) = D(f)` if declared else `I(f)`. Callers, `front_attrs`, contracts, threads and `--check-alloc` read `S(f)` (today they read `I(f)`, T14).
- E3.2 `I(f) ⊆ D(f)` for every declared `f` with a body (`effect.declared`, with `--why`); C declarations are trusted.
- E3.3 (parametric declarations.) `#[effects(E₁.., P₁..)]` with each `Pⱼ` a type or callback parameter: `D(f⟨τ⟩) = {E₁..} ∪ ⋃ⱼ S(τⱼ)`, where `S(τ)` for a closure/fn type is its body's set and for a type parameter with trait bounds is `⋃ S(m)` over the bounds' methods at `τ`; checked per instance. A bound `F: FnMut(&T) -> bool + effects(alloc(A), panic)` is an upper bound on `S(F)` checked at the binding call.
- E3.4 (who declares.) std2's `pub` items (written by `fix --only effects` in E3.3's form; a body outgrowing its declaration is an error in std2), trait method declarations (binding every impl: `I(I::m) ⊆ D(Tr::m)`; an impl may declare a smaller set that callers through the bound do not see), `extern "C"`. A program's items infer; no lint (closed world, no separate compilation).
- E3.5 (stability.) A declared function is a fixed point of E5's propagation: a body change cannot alter a caller's `S` without an error at the declaration.
- E3.1a (0.27.2.1, what `S(f)` holds.) For a declared function of the rust edition with a body, `S(f)`'s visible bits and allocators are `D(f)`'s (E3.3a's form for a generic one); its hidden bits (`raw_panic`, `raw_diverge`, `raw_global`, `interior`) and `unsafe` are `I(f)`'s: they are the optimizer's and the threads check's, never part of a signature, and `D(f)` cannot lower them. E5.3's propagation gives a caller `S(f)` in place of `I(f)`; `effect.declared` compares `I(f)` with `D(f)`. An MVS function keeps `S(f) = I(f)` until 0.28 (MVS programs compile as before).
- E3.3a (0.27.2.1, the parametric form as built.) An item of `#[effects(..)]` that names a type parameter `P` of `f` or of its impl is a parametric item. For an instance `f⟨τ⟩`, an edge of `f⟨τ⟩` is *made for `τ_P`* when its callee's self type or one of its type arguments mentions `τ_P` (is it, or has it as a part: a reference's, a pointer's, an array's, a slice's or a tuple's element, a struct's or an enum's type argument), when it is the body of a closure whose type mentions `τ_P`, or when it is a fn type's virtual node (E4.3) whose type mentions it. `Px(f⟨τ⟩)` is the union of `through(S(g), kind)` over the edges made for a listed parameter; `D(f⟨τ⟩) = {E..} ∪ Px(f⟨τ⟩)`, with `{E..}` the list's other items resolved in the instance (`alloc(A)` names `τ_A`). Two more parts pass through every declaration: what comes from a call through a fn value, directly (an edge to a fn type's virtual node) or through callees (each node's set is kept split, `fixed ∪ dyn`, `dyn` the part from fn values: E4.3, what such a call reaches is the program's, closed world, as a type argument's instance is), and, when a parameter is listed, a drop's edges (E4.4: the drop of a `T` reaches its parts' drops, `String<A>`'s Vec) and the allocators `f`'s own body names that a listed parameter's type mentions or that mention it (a drop of a `T = Vec<_, Gpa>` frees through `Gpa`). A list item that is a capitalized name is taken for a parameter (a type's name is never an effect's); one that names none in an instance adds nothing. So `I(f⟨τ⟩) ⊆ D(f⟨τ⟩)` checks what `f` does itself and through the callees not made for a listed parameter; what it does through them is its callers'. This replaces E3.3's `S(τ)` (the bound's methods at `τ`) for 0.27.x: it needs no method table and gives callers the exact set; its check is weaker where a generic callee made for `τ_P` adds effects of its own (they pass through). E3.3's strict form is R7's.
- E3.3b (0.28.0, what is checked in a program's function.) For a function outside std, `I(f)` is its body's own set, a cycle's diverge, and each edge's: a call of the program's or through a fn value, the callee's whole set (`fixed ∪ dyn`); a call of a declared std function, `S(g)` (its list, and its hidden bits); a call of an undeclared std function, its whole set. So a `println` in a `#[no_io]` function, a Drop that prints reached by a drop, a closure the body makes and calls are the function's, as MVS's. What passes a parametric declaration of the program's (`Px`) is the edges made for a listed parameter, with their fn values' parts; std2's own declarations keep E3.3a's form (a fn value's call passes).
- E3.6 (0.27.2.1, writing and counting declarations.) `volec fix --only effects` gives every `pub` function and inherent `pub` method of the rust edition without a declaration (trait methods, their default bodies and trait impls' methods are E3.4's, through the trait; `pub(crate)` counts as `pub`) the list of its set: for a non-generic one `I(f)`'s visible bits and allocators; for a generic one the union over the program's instances of `I(f⟨τ⟩)` minus the edges made for a type parameter (E3.3a), an allocator that is a type argument written `alloc(P)`, and each parameter some instance has such an edge for listed. `--only effects-std` prints std's own items instead (std2's, from a program that uses them; `effects-std-all` with every std2 body checked, as `--std2-check`), a line each, `<std>:LINE<TAB>LINE TO INSERT`, which `tools/std2-effects.py` writes into compiler/std2, the union over the programs it is given. `query items M --undeclared` lists `M`'s undeclared `pub` functions and methods (the same set) and ends with `undeclared: N of M`.

**E4 (closures, trait methods, fn values, drops).**
- E4.1 A closure is a body; `I(closure)` is exact per instance; a closure value's call has an edge to that body.
- E4.2 A call through a bound `T: Tr` is, per instance, a direct call of the concrete `I::m`; `S(I::m) = D(Tr::m)` if the trait declares, else `S(I::m)`. No `dyn`.
- E4.3 A call through a `fn` value: closed world, an edge to every function of that type whose address is taken (`OK_FN` operands); through an `extern "C" fn` value: unknown C.
- E4.4 `SK_DROP drop(P)` with decision `≠ DS_REMOVED`: edges to `type(P)`'s `Drop::drop` and its fields' drop functions (`drop_fn_at`, as 0.26.1) **[V]**. `Allocator::FREES = false` removes a container's free: no `alloc(A)` from such a drop (decision 10).
- E4.4a (0.27.2.1, `FREES` as built.) A call of `deallocate` of an `impl Allocator for A` whose `const FREES` is `false` adds no `alloc(A)` (E5.1's allocator row): its deallocate gives nothing back by the trait's contract. `FREES` is read from the impl for `A` with references peeled (`impl Allocator for &A` has `A::FREES`); an impl that does not write it has the trait's default, `true`. So a container's drop on an arena, a scope or a FixedBuf has no `alloc(A)` from its free; `alloc(A)` stays on what allocates.

**E5 (inference on the places IR).** `I` is the least solution of `I(f) = L(f) ∪ ⋃_{(f→g)} through(S(g), kind)` over `G = (Bodies ∪ Virtual, Edges)`:
- E5.1 `L(f)` per construct of the elaborated body (constants of `places/ir.vl`):

| construct | adds |
|---|---|
| `SK_ASSERT (op, AK_BOUNDS/AK_RANGE/AK_ENUM)` | `panic` unless discharged (L4.1) |
| `SK_INTRINSIC IK_CONTRACT` (a clause's or assert's failure path) | `panic` unless its switch is discharged or `proven_true` as written |
| `SK_INTRINSIC IK_PANIC` | `panic` |
| `SK_ASSIGN _ = RV_BINARY` or `RV_CHECKED` with `BO_ADD/SUB/MUL/SHL/SHR` on an integer type, in a body outside `std::num::wrapping` | `panic` unless discharged (`overflow_ruled_out`). **E5 reads the operator and the type, never `checks_here`/`RV_CHECKED`**: the IR's choice of rvalue follows `-O` (T13a) and effects may not |
| `SK_ASSIGN _ = RV_BINARY BO_DIV/BO_REM` on an integer type | `panic` unless the divisor's range excludes 0 and, for a signed type, the pair `(MIN, -1)` (L1) |
| `TK_GOTO` with the back-edge bit of an uncounted loop | `diverge` |
| a cyclic SCC of `G` | `diverge` for every member |
| `SK_CALL` of an `unsafe fn` or C; `PJ_DEREF` on a raw-pointer place; `RV_CAST` int→pointer; `PJ_UNION` read; `OK_FN` of an `unsafe fn` | `unsafe` |
| an operand or place rooted at an `LF_STATIC` local of a `static mut`/C static | `static` (+ `raw_global` unless a `std.thread.*` guard) |
| `SK_INTRINSIC IK_ARCH` atomics/fences; thread-local roots | `sync unsafe`; `tls` |
| `SK_CALL` of `UnsafeCell::get` | `interior` |
| `SK_CALL` of an `impl Allocator for A` method | `alloc(A)`; the edge passes only `raw_panic`, `raw_diverge` |
| `SK_CALL` of `arena_scope`/`scope` | the callee's set minus the scope's arena plus the parent's |

- E5.2 `Edges`: `SK_CALL` direct → `f`; closure value → its body; `fn` value → the virtual node (E4.3); drops (E4.4). `through(S, E_CALL) = S \ {unsafe}`; `E_ALLOC`, `E_SCOPE` as today.
- E5.3 Solve: Tarjan over `G`, bottom-up union per SCC; a declared node contributes `D(f)` and is not re-propagated into (E3.5). `O(|stmts| + |Edges|)`.
- E5.4 Runs after elaboration and borrowck, before `check_contracts`, `threads` and lowering, at `check`, for every body; gated by `rust_fn` in 0.27.x (MVS bodies keep the AST walk until 0.28; both feed `FN_EFFECTS`; `--verify-effects` is the witness that they agree on shared callees).
- E5.5 The syntactic `in_bounds` rule is retired for rust bodies: its cases are L4.1 verdicts on the `SK_ASSERT` (the counted-loop fact `i < s.len()` with `s` unwritten), by one procedure that is fixed and `-O`-independent, so the guide's promise holds.
- E5.6 (arithmetic, decision 13 made exact.) Integer `+ - * << >>` and `/ %` are `panic` in `I(f)` unless discharged, at every `-O` and either overflow setting. A `#[no_panic]` function must have every such statement discharged by L1 or written `wrapping_*`/`checked_*`, and call only callees whose `S` lacks `panic`. At `-O1+` overflow checks are off and no `Ovf` exists in the SSA IR, so the optimizer's `NOPANIC` (from `compute_attrs`) is unaffected; the front's `panic` bit is the strict one, and `query effects` output changes everywhere (release notes, guide).

**E6 (allocation as a capability).** `alloc(A)` names the type; capability is the type system's (decision 1). `AnyAlloc<'a>`: `alloc(AnyAlloc)`, opaque: `#[no_alloc]` refuses it; `#[effects(alloc(FrameArena))]` admits a newtype arena only. `FREES` is E4.4's. Threads: `spawn_in<F: FnOnce() + Send + effects(alloc(A), panic)>` is E3.3's bound.

**E7 (what requires effects).** Contracts: C4. `#[no_panic]`: N1. Threads: `sync.global` iff `raw_global ∈ S(f)` of the spawned body (reading `S`, not `I`).

**E8 (soundness).** For an accepted program, every function `f` and every execution of `f` at any `-O` and overflow setting: an action of class `c` performed implies `c ∈ S(f)`, except through (i) a wrong C declaration, (ii) an `unsafe` operation performing the action without the construct E5.1 names (a raw write into a static through a forged pointer): such an `f` carries `unsafe` and its SAFETY comment owns the gap — the lattice is sound modulo the SAFETY obligations of the unsafe code it contains, as Rust's `noalias` is; (iii) a ⊤ body. `S(f)` may over-approximate.

## 3. Static analysis

**L1.0 (Level 1).** `L1(b)` is a deterministic procedure on the elaborated, borrowck-solved places IR body `b`, before lowering to SSA, independent of `-O` and inlining, run at `check`. Output: a fact table `F(b)` and a verdict per check site `k`: `Discharged(k, reason)`, `Refuted(k, witness)`, `Runtime(k)`. It is the range procedure (`decide`, `interval.vl`, `narrow_by_facts`, `chained`, `rem_below`, `overflow_ruled_out`) re-hosted: the same decision rules, L1.2's sources, no SSA. `interval.vl`'s transfer functions are factored into a module both hosts use.

**L1.1 (domain).** Per integer-typed local an interval in the signed-64 view of the canonical value, the congruence `x % n ∈ [0, n)` for `n ≥ 1`, and equality classes from `==` facts. Non-integer locals and projected places are ⊤ unless a fact names them.
- L1.1.1 A local is *single-assignment* iff `LF_SSA` or a non-`LF_MUT` user local; its value is its one rvalue. A `LF_MUT` local or a projected place is *killable*: facts about it hold from the statement that established them until the first statement that may write it (A1).

**L1.2 (fact sources).**

| source | fact | holds | kind |
|---|---|---|---|
| `TK_SWITCH l` with `l = RV_BINARY BO_cmp (a, b)`, `l` single-assignment | `a cmp b` on the `1` edge, `¬(a cmp b)` on the `0` edge; `l == v` on a one-target integer case | points dominated by the edge's target when it is the target's only predecessor (`collect_facts`, ≤ 64 steps) | checked |
| `SK_ASSERT`'s / an `IK_CONTRACT` switch's passing edge | the asserted comparison or conjunct | after | checked |
| `SK_ASSIGN t = RV_LEN P` | `t ≥ 0`; `t == n` for `[T; n]` | after | proven |
| `SK_CALL t = call len/is_empty/capacity` of std2's containers (table: `Vec`, `String`, `[T]`, `str`, `VecDeque`, `HashMap`) | `t ≥ 0`; `Vec::len() ≤ capacity()` | after, until a write or `M` loan of the receiver (A1) | proven |
| counted `for` (the builder's guard switch on `i < n`) | `i < n`, `i ≥ start` in the body (the switch row plus A1: `i` is written at the latch only) | body | checked |
| `SK_ASSIGN t = RV_BINARY BO_REM (x, n)`, `n ≥ 1` | `0 ≤ t < n` (unsigned, or signed with `x ≥ 0`) | after | proven |
| entry of `f` with non-debug `req_eff(f)` (L3.2) | each conjunct over the parameters | entry | checked |
| after `r = call g(..)` with non-debug `ens(g)` (L3.3) | admissible conjuncts, `result := r`, `pᵢ := aᵢ` | after | checked |
| after `r = call g(..)` with non-debug `req(g)` (L3.4) | conjuncts over `&T` (`T: Freeze`) and slot-free `Copy` arguments | after | checked |
| a place `P` of type `S` with `inv(S) ≠ []`, outside `S`'s module (C9.7) | `inv(S)[self := P]` | where `P` is `DefInit` (D8.2) | proven |
| the type of `l`; `RV_CAST`, shifts, masks, constants | `[min(τ), max(τ)]`; `interval.vl`'s transfers | always / after | proven |
| one step of transitivity (`chained`), same signedness | `a R w ∧ w R' b ⇒ a R'' b` | where both hold | derived |

No fact of any other kind exists: a `debug` clause, an invariant inside its module, a clause of `main`, give nothing.

**L2 (side conditions).** L2.1 a fact over a `PJ_DEREF`/`PJ_INDEX` place is admitted only with A1. L2.2 signedness as `decide`. L2.3 intervals are of the canonical value; `i + 4 <= len` gives `i + k < len` only when `i`'s interval excludes wrap, which `usize` lengths now give (the 0.26 `usize` decision closes the 0.18.1 "window" gap). L2.4 one transitivity step (K-U1), a second after measuring. L2.5 `debug` clauses yield nothing. L2.6 invariant facts only outside the module and only for `Freeze` `S`.

**L3 (clauses as facts).**
- L3.1 In the caller: the passing edge of each `requires` conjunct's switch at the site.
- L3.2 Entry facts: for `f` with non-debug `req_eff(f)`, at `bb0[0]`, each conjunct over `_1.._n`, kind checked, iff every entry of `f` runs `f$pre` first: direct calls do (T3); indirect calls and `extern "C"` exports go through `f$checked` (L5.2); `main` has no caller. With L5.2 the exception list of today's `entry_pre` leaves the soundness side; whether the optimizer re-evaluates the companion at the entry stays its cost choice (O1.2).
- L3.3 Result facts: after `r = call g(a₁..aₙ)`, a conjunct `φ` of non-debug `ens_eff(g)` is a fact iff `free(φ) ⊆ {result} ∪ {pᵢ | type(aᵢ) slot-free Copy without raw pointers} ∪ {old(e) | e over such pᵢ}`, substituted as the argument values were (the `?aᵢ` temporaries). A conjunct over `*v` for `v: &mut T` is not propagated in 0.27–0.29 (kept in `F` as `Runtime`-kind provenance for Level 2).
- L3.4 The callee's `req(g)` conjuncts over `&T` (`T: Freeze`) and slot-free `Copy` arguments survive the call (plan §5); anything reachable from a `&mut`, a raw pointer or an `UnsafeCell` is dropped.
- L3.5 In `g`'s wrapper, after the `ensures` switches pass, the conjuncts are facts for the rest of the wrapper (C9.2a crossings that follow).

**L4 (verdicts).** For a site `k` with condition `c` at point `p`, `d = decide(c, F(b), p)`:
- L4.1 `d = 1` ⇒ `Discharged`: the statement's decision field becomes `AS_DISCHARGED` (`AS_UNDECIDED=0, AS_KEPT=1, AS_DISCHARGED=2, AS_REFUTED=3`, a field of `SK_ASSERT` and of a conjunct switch); both code generators emit nothing for it; `c` remains a fact (a theorem); no `panic` (E5.1); `--print-checks`: `removed (L1: reason)`.
- L4.2 `d = 0` ⇒ `Refuted`: C11's error (or `--allow` → `Runtime`, C11.1).
- L4.3 `d = -1` ⇒ `Runtime`: as today.
- L4.4 Determinism: `L1` is a function of the body alone; a release may discharge more; a new refutation source lands with a release note and a one-release `--allow` (K-U2).
- L4.5 Budget: `T_LEVEL1 ≤ 10%` of `T_CHECK − T_OWN − T_PLACES_*` on the rust corpus and on compiler/src after 0.28; MVS 1.00x in 0.27.x (`rust_fn`). Mitigations in order: skip bodies with no check site, cap `collect_facts` depth, index facts by root local.

**L5 (entries).** L5.1 direct calls: `f$pre` at the site. L5.2 `f$checked`: for every `f` with non-debug `req_eff(f)` whose address is taken (`OK_FN f`; a coercion to an `fn` type; an exported `extern "C"` definition), the fn value and the exported symbol are `fn f$checked(<params>) -> R { f$pre(SITE_INDIRECT, <params>); f(<params>) }` (`FN_DERIVED`); `SITE_INDIRECT` prints `f`'s definition and `--trace` adds the caller. Then L3.2 holds at every entry and `strip_taken`'s address-taken half is deleted. L5.3 `main`, variadics: no entry facts.

**N (`#[no_panic]`).**
- N1 `#[no_panic] fn f` is accepted iff `panic ∉ I(f)` under E5 with L4: every `SK_ASSERT`, `IK_CONTRACT`, arithmetic, `/`, `%` of the body discharged, every callee with `panic ∉ S`, every drop edge panic-free. `effect.declared` with `--why panic` naming the statement; `try:` per source: an index → `get(i)` or iterate; a callee → declare it `#[no_panic]`; an arithmetic site → `'x + y' at FILE:L:C may overflow: write 'x.wrapping_add(y)' (wraps), 'x.checked_add(y)' (an Option), or add 'requires x < K' / 'requires x < v.len()' so the range analysis can prove it` (the third form when one operand is a parameter and the other a constant, a `len()` or a parameter); `/`, `%` → `'requires n != 0'` (and `n != -1` or an unsigned type).
- N2 Checked at `check`, the same at every `-O`; a proof relative to E8.
- N3 (strict, K-U4.) An `ensures` on a `#[no_panic]` function is checked in its wrapper, which is the function's body: it must be `Discharged` by L3.5 facts or the declaration fails (`help: an ensures that may fail is a panic; prove it or drop #[no_panic]`).
- N4 `front_attrs` reads `S` (E3.1), so a declared `#[no_panic]` gives `NOPANIC` to every call of it.
- N5 (estimate, **[I]**.) No measurement exists (std2 has no declarations; `--print-effects` prints the program's functions only). Of std2's 568 `pub fn`, about 20–25% are `panic`-free under today's syntactic rule (accessors: `len`, `is_empty`, `capacity`, `as_ptr`, `is_some/none/ok`, `Layout::size/align`, `by_ref`, `erase`, scalar `Default`/`Clone`, comparisons); under E5.6 with L1 discharging counted loops and `len`-bounded indexing, 10–15% without edits; with `wrapping_*` in hashing/formatting and `requires` on `split_at`/`chunks`, about 25%. The number printed from 0.27.4: `query effects std --has panic --count` before and after; the plan's candidates (`slice::len`, `Layout::*`, the hash loop) must be in the passing set.

**A (composition with borrowck).** Read: the loan table (`RO_LOAN` rows), `scope(p)` (D2.4), `rel`/`Overlap` (D1.5), universals and parameter types.
- A1 (kill rule.) A fact `φ` over place `P` established at `s₀` holds at `p` iff on every path `s₀ → p` no location `s` may write `P`: `s` performs a `W*` access (`WA`, `WB`, `WM`, `WD`, `Activate` of an `M` loan) to a `Q` with `Overlap(P, Q)`; or `s` is a call/intrinsic and some `ℓ ∈ scope(2·s)` of class `M` has `Overlap(P_ℓ, P)`; or `P` is reached through a raw-pointer deref (any call or raw write kills it) or through a deref of a non-`Freeze` `&T` (any call kills it); or `s` writes a `static` root of `P`. A forward dataflow with gen at `s₀`; the call case is a bitset test over `scope`.
- A2 (`&mut` parameters are not aliased: I3/I7.) For `p: &'a mut T` of `b`, every `Q` of `b` with `Overlap(*p, Q)` has `root(Q) = p` or is a reborrow chain from `p` (I3′): a fact over `*p.π` is killed only by a write rooted at `p` or through a reborrow of `p` (A1 covers the call case). A call receiving neither kills nothing over `*p`.
- A3 (`&T`, `T: Freeze`.) A fact over `*q.π` for `q: &'a T` is killed by nothing inside `b` (no `M` loan of `*q..` can exist: a `WB` through a shared deref is rejected by D2.5/D1.2). Raw writes are the SAFETY comment's; Tree Borrows under `--check-unsafe` is the dynamic check (R6).
- A4 (what borrowck does not give.) Parameters carry no loan rows (`assign_regions`: `RO_UNIVERSAL` only) **[V]**, so the disjointness of two `&mut` parameters is not derived from `scope`; it is the axiom A4.1. Nothing about heap objects behind `Box`/`Vec` beyond the container table (`vecfacts`, O3.3); nothing after an unsafe raw write.
- A4.1 (axiom with premise.) In `b`, `p: &mut T` and `q: &mut U` satisfy `Overlap(*p.π, *q.ρ) = false`, and `p` is disjoint from every `r: &V`, provided every caller of `b` established it: a borrowck-accepted rust caller (at the call the two `M` loans, or the `M` and `S` loan, are both in `scope`, and D2.5 rejects the second's creation or activation when the places overlap), or `unsafe` code whose SAFETY owns it. Exceptions, where A2 and A4.1 are off for `b`'s parameters: (a) `b` is an `extern "C"` definition, `main`, or address-taken as an `extern "C" fn` value (a C caller may alias), and `f$checked` when it is the exported symbol; (b) 0.27.x only: `b` is reachable as a callback from MVS std through the §12 bridge (D12.2: "nothing in MVS std's body is solved"; MVS std is trusted like unsafe code; there are no mixed-edition programs, so std's are the only MVS callers of a rust body) — closed in 0.27.2 by std2; (c) a D10.4-deferred closure body's captured places (reached through the raw env): no A2; its parameters are fine (their callers are checked); covered by O3.4's `borrowck_clean = false` for that body.
- A5 (contracts' accesses.) bc271 D17.1 holds; this design adds D17.4 (C3), D17.5 (C5), D17.6 (A4.1), D17.7 (O3.4). bc271's "Finding" (the property-test generator refuses `&T`/`&mut T` parameters, so contracted rust functions with reference parameters do not check) is ir271's fix in 0.27.1.

**V (Level 2 hooks, designed now).** V1 every check site has a stable id (the site table plus the conjunct index); `--emit-places` prints `assert .. [site N, conj k]; L1: discharged|runtime|refuted (reason)`. V2 `F(b)` is dumpable by `check --emit-facts` in the regions dump's style (bc271 §16): `fact bb0[3+]: _2 < _5  (switch bb0[2], checked)`, `verdict site 14/0: discharged (chained: _2 < _5, _5 <= _7)`; this format is Level 2's only interface. V3 `volec verify` takes `(b, F(b), verdicts)` and may change `Runtime → Discharged` with a proof reference, never `→ Refuted` without a model, and never adds a fact of a new kind; the compiler re-runs L4.1 for upgraded sites; an `assume` is not an input anywhere. V4 clause terms are pure (C4), first-order over integers, bools, places and pure calls; `old` temps are plain locals; trait clauses are inherited, so a bound-polymorphic body verifies once against `req(Tr::m)`/`ens(Tr::m)`. V5 decision 14 stands: no `volec verify` before compiler/src carries 100 clauses (`query stats` prints the count from 0.28.0).

## 4. The optimizer

"Checked" means the check runs on every path to the use in the final program, or was discharged as a theorem (L4.1).

- **O1.1** The passing branch of a `requires`/`ensures`/`assert`/invariant switch gives its condition (today, `is_check`): sound because the failing side ends the program.
- **O1.2 (entry facts).** With L5.2 every entry of a contracted `f` checks `req_eff(f)`, so the entry may assume it at every `-O`. Implementation stays T8's (`f$pre(ENTRY_SITE, ..)` at the entry, `entry_assumes`, `drop_assumes`); the gate becomes: `f ≠ main`; the clauses `cheap` (a cost condition); `never_inlined(f)` (a performance condition: the measured regression with facts everywhere, prefix 218M → 582M, stands). `strip_taken`'s address-taken half goes. Non-cheap clauses: `F(b)`'s entry conjuncts that are comparisons of parameters and constants are lowered as an empty `assume` branch on the parameters' entry values; others give nothing at -O2.
- **O1.3 (result facts, IPO).** `ipo::result_facts(g)`: per L3.3-admissible conjunct a template over `(result, args)`; at `r = call g(..)` the caller adds it as an `assume` branch after the call, emptied like entry facts. Sound: the wrapper checked it (or discharged it). Survives inlining as a branch.
- **O1.4** An `AS_DISCHARGED` site lowers as a jump, its condition kept as a fact through an `assume` branch dropped by `drop_assumes`.
- **O1.5** Never: a fact from a `debug` clause, from an invariant inside its module, from a refuted-but-allowed site (C11.1), or an `#[assume]`; a wrong contract is never UB.
- **O2.1 (effects → attributes).** `front_attrs(f)` reads `S(f)`: `WILLRETURN ⇐ diverge, raw_diverge ∉ S`; `NOPANIC ⇐ panic, raw_panic ∉ S`; `READONLY ⇐ io, alloc(·), alloc_extern, static, interior, sync, thread, tls, unsafe ∉ S ∧ every parameter is &T with T: Freeze, or slot-free Copy without raw pointers`; `READNONE ⇐ READONLY ∧ no &T or view parameter`. C functions as today. `compute_attrs` refines; `call_attrs` ORs both.
- **O2.2 (per pass).** GVN: `READNONE` calls across dominators; `READONLY` within a block with no intervening write. LICM: `READNONE` + invariant args, speculated only with `WILLRETURN ∧ NOPANIC ∧ BOUNDED`, else `runs_first`. Dead-call elimination: `READNONE ∧ WILLRETURN ∧ NOPANIC`. Reordering two calls: both `READONLY`, or one `READNONE`, and neither `io`. `sync/thread/tls/interior` turn `READONLY` off.
- **O2.3 (`#[no_panic]`, `nounwind`).** Every call is `nounwind` (decision 18) independently of `#[no_panic]`; `#[no_panic]` gives `NOPANIC` by O2.1. When unwinding lands, `NOPANIC` becomes `nounwind`; nothing here changes meaning.
- **O3.1 (`noalias` on `&mut` parameters).** For a rust body with `p: &mut T`: no load or store through a base not rooted at `p` (or a reborrow of it) aliases `[*p, +size_of(T))` — A2 under A4.1's premise. Used by `gvn::may_alias` (`params_disjoint`; `param_frozen` generalised: a `&mut` referent is written only by stores rooted at it and by calls receiving a reborrow), LICM's `blocks_may_write`, the vectorizer's legality. Conditions: O3.4; `T` without `UnsafeCell` for the `readonly` half; a body with local `unsafe` loses its parameters' `noalias` until `--check-unsafe` with Tree Borrows is the gate row's witness (R6); A4.1's exceptions apply.
- **O3.2 (`readonly` on `&T`, `T: Freeze`).** No store in the body or any callee writes `*q` (A3): loads through `q` are invariant and forwardable across calls (today's `param_frozen` without its "passes it to no call" conservatism).
- **O3.3 (Vec facts).** `vecfacts` stays for std2's `Vec<T, A>` by name, justified by A2/A3; "a buffer never holds its header" is std2's SAFETY obligation.
- **O3.4 (the gate; 0.27.1, bc271 M3).** `noalias_active(fi)` is per body: for `rust_fn(f)`: `borrowck_clean(f)` — the solve ran on `f`, reported no error, and `f` is not a D10.4-deferred body; for an MVS body: `own_mode == MODE_ERROR`; `!noalias_off` for both. The three readers (`params_disjoint`, `param_frozen`, `vecfacts` through `vec_apart`) take `fi`; the code cache's key takes the body's borrowck verdict. **Stopgap until M3 lands: `rust_fn(f) ⇒ false`.** Witness: T16's program as `tests/run/rust_b_alias_params.vl` expecting `borrowck.mut_twice` and `borrowck.conflict`; `same-output` over `rust_t_*`/`rust_b_*` at -O0 vs -O2, with and without `--no-noalias`.
- **O4 (survival across inlining and IPO).** Entry, result and discharged facts survive inlining as branches. `S(f)` is per symbol and stable (E3.5). O3's parameter facts are used before inlining in the callee and, in the caller, only through `call_attrs`: after inlining the reborrow is a loan the SSA IR does not carry (K-U5: `noalias` scopes through inlining are a later optimizer item). The code cache keys include `S(f)` and the body's L1 verdict table.
- **O5 (measurement, every release).** (a) `--print-checks` totals over bench, examples and (from 0.28) compiler/src: `left / removed (ranges) / removed (L1: reason) / removed (contract) / refuted (allowed) / invariant_deep`, in `bench/run.sh`'s report; (b) `--print-effects` histogram: shares of `none`, `panic`-only, `static`, `alloc`; (c) the pair `contracts` vs `contracts_plain` (0.18.1: 4383M vs 5871M, −25%; target: at most that ratio, with the window kernel no longer +24% once L2.3 applies); (d) `purecall` ≤ 1.05 (exists); (e) `arena_trees` ≤ 32 ms (exists); (f) compiler/src at -O2 index checks left (10,942 at 0.25.5), re-based at 0.28.0 after K-I5's survey.

## 6. Risks and divergences

**Risks.** Compile cost at `check` (L4.5, the 10% budget and its mitigations; MVS safe by `rust_fn`). `panic` noise (E5.6: `query effects` output changes everywhere; release notes and the guide). Refutations break builds (L4.4's note-plus-`--allow` rule). `f$checked` and C callbacks (L5.2: exported symbols become wrappers; the gpu callback paths re-run). Two walks feeding one `FN_EFFECTS` in 0.27.4 (`--verify-effects` is the witness). Unsafe code under `noalias` until Tree Borrows (O3.1). The miscompile of T16 until bc271 M3 lands (the stopgap closes it for rust bodies at the cost of their alias facts).

**Divergences, each with its reason.**
- **Rust** has neither contracts nor effects; vole keeps both for the measured wins (plan §9.2–§9.3) and the compiler's computed indices. Rust's `unconditional_panic` is promoted to `contract.violated`/`check.unconditional` with intervals (C11). Rust's `+` panics in debug and wraps in release; vole copies that (decision 6) and makes `#[no_panic]` the strict proof Rust's no-panic crates do by hand (E5.6).
- **Ada SPARK**: proof obligations with `pragma Assume`; vole never assumes (O1.5), checks at run time by default, proves only with its fixed Level 1. SPARK's `Global`/`Depends` are the fine-grained form of vole's coarse `static`/`io` bits, which are what the optimizer and threads need.
- **Dafny**: mandatory verification, no run-time check; vole's clauses are executable and always checked (0.18 decision 1; no UB; agents' workflow).
- **Prusti/Creusot**: ghost specifications with prophecies (`^v`); vole writes the final value as `*v` at exit (C2.2, D17.3) and the initial as `old(*v)` (C5): the same information by evaluation order, possible because clauses execute. Pledges and ghost state are Level 2's (V4).
- **Eiffel/Spec#**: invariants at every public entry and exit, or pack/unpack; vole checks at the exit boundary and before callbacks (C9.2) and relies on exclusivity (I3): no pack/unpack state, no entry check. Eiffel's `require else` (weakening) corresponds to C7.1's impl `requires`, which vole allows as a checked, per-instance precondition rather than a provable weakening.
- **Koka/Effekt**: handlers, row polymorphism, effect variables in types; vole has none: effects are not control, and whole-program monomorphization makes every instance exact (E4, E5), so quantification is confined to declarations on generic `pub` items (E3.3). The price is no separate compilation against an effect-polymorphic signature, which vole does not have anyway.
- **Rust's `noalias` to LLVM** is trusted under Stacked/Tree Borrows; vole consumes the same facts in its own passes (O3) and makes `--check-unsafe` the witness (plan §5).
